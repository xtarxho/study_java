Group 3 섯다 - 멀티플레이 사용 방법
===================================

1. 프로그램은 기존처럼 sutda.Main 을 실행합니다.
2. 로그인 후 게임 모드 선택 화면이 나옵니다.

[혼자 하기]
- 기존 AI 3명과 하는 게임입니다.

[방 만들기]
- 한 사람이 "방 만들기"를 누릅니다.
- 이 사람의 컴퓨터가 서버(호스트)가 됩니다.
- 게임 화면 왼쪽 위와 로그에 "호스트 IP"가 표시됩니다.
- 예: 192.168.0.15

[방 참가]
- 다른 사람들은 같은 Wi-Fi/공유기에 연결합니다.
- 로그인 후 "호스트 IP 입력" 칸에 방을 만든 사람의 IP를 적습니다.
- "방 참가"를 누릅니다.

3. 2명 이상 들어오면 호스트의 "게임 시작" 버튼이 활성화됩니다.
4. 최대 4명까지 같이 플레이할 수 있습니다.
5. 자기 차례일 때만 콜 / 다이 / 더블 / 올인 버튼이 활성화됩니다.
6. 한 판이 끝나면 아무 참가자나 "다음 라운드"를 눌러 다음 판을 시작할 수 있습니다.

네트워크 참고
-------------
- 기본 포트: 9999
- 같은 컴퓨터 테스트: 참가 IP를 127.0.0.1 로 입력
- 같은 공유기에서는 보통 192.168.x.x 형태의 호스트 IP를 사용합니다.
- Windows 방화벽에서 Java 네트워크 허용 창이 뜨면 같은 사설 네트워크에서 허용해야 합니다.
- 학교/회사 Wi-Fi처럼 기기끼리 통신을 막는 네트워크에서는 같은 Wi-Fi여도 연결되지 않을 수 있습니다.
- 인터넷을 넘어 다른 장소에서 접속하려면 공유기 포트포워딩/VPN 같은 별도 설정이 필요합니다.

발표용 핵심 설명
----------------
- SeutdaServer: 카드, 돈, 팟, 차례, 승패를 한 곳에서 계산
- SeutdaClient: 서버에 접속하고 행동 명령을 전송
- MultiplayerFrame: 서버가 보내준 같은 게임 상태를 각 컴퓨터 화면에 표시
- GameModeFrame: 혼자 하기 / 방 만들기 / 방 참가 선택
